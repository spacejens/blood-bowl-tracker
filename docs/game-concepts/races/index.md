# Races

A [race](../../glossary.md#race) defines the species or faction of a [team](../teams/index.md) and determines which [positions](../positions/index.md) its players may hold.

- A race has a name.
- A race's availability is a property of the [eras](../eras/index.md) it was allowed in, not of [rules sets](../rules-sets/index.md) directly.
- A race has one or more [positions](../positions/index.md).
