# Match Events

A [match event](../../glossary.md#match-event) records a noteworthy occurrence during a [match](../matches/index.md).

- A match event belongs to exactly one [match](../matches/index.md).
- A match event may reference an acting [team era](../team-eras/index.md), a consequence team era, an acting [player](../players/index.md), and a consequence [player](../players/index.md); all are optional.
- A match event may record that its acting participant or consequence recipient was not an identified player — a journeyman, a mercenary, a star player, or the crowd/a random event — as far as the source could tell.
- A match event may record a casualty that was _prevented_ (by an apothecary or by regeneration) rather than one that took effect: the event says which severity was prevented and how, and is deliberately not counted as a casualty suffered.

Match events are complex and will be specified further in a future document.
