# Match Events

A [match event](../../glossary.md#match-event) records a noteworthy occurrence during a [match](../matches/index.md).

- A match event belongs to exactly one [match](../matches/index.md).
- A match event may reference an acting [team era](../team-eras/index.md), a consequence team era, an acting [player](../players/index.md), and a consequence [player](../players/index.md); all are optional.

Match events are complex and will be specified further in a future document.
