# Rules Sets

A [rules set](../../glossary.md#rules-set) is a specific published edition or version of the Blood Bowl rules.

- A rules set has a name.
- A rules set may be referenced by one or more [eras](../eras/index.md) across different [leagues](../leagues/index.md).
- A rules set prices a player's [advancements](../../glossary.md#advancement) in [SPP](../../glossary.md#star-player-points-spp). CRP, CRP+ and BB2016 use fixed thresholds of 6, 16, 31, 51, 76 and 176 SPP: reaching each one earns a roll on the rules set's advancement table. BB2020 and DB2021 instead price each advancement by what the coach takes (a random or chosen primary skill, a random or chosen secondary skill, or a random characteristic increase). BB2025 prices by what the coach takes in the same way, but has no random secondary skill option. Costs are recorded per advancement (under fixed thresholds, the gap to the previous threshold) rather than as cumulative thresholds, so [unspent SPP](../players/index.md#unspent-spp) follows one rule for every rules set: total SPP minus the costs of the advancements gained. A [league](../leagues/index.md) can add its own house-rule advancements on top of these, which never replace the rules set's.
