# Rules Sets

A [rules set](../../glossary.md#rules-set) is a specific published edition or version of the Blood Bowl rules.

- A rules set has a name.
- A rules set may be referenced by one or more [eras](../eras/index.md) across different [leagues](../leagues/index.md).
- A rules set prices a player's [advancements](../../glossary.md#advancement) in [SPP](../../glossary.md#star-player-points-spp). CRP, CRP+ and BB2016 use fixed thresholds of 6, 16, 31, 51, 76 and 176 SPP: reaching each one earns a roll on the rules set's advancement table. Costs are recorded per advancement (the gap to the previous threshold) rather than as thresholds, so unspent SPP follows one rule for every rules set: total SPP minus the costs of the advancements gained.
