# Prototype implementation

An earlier prototype of `import-bbl` exists in a separate repository. It is
inefficient and **not** a good template — using it risks importing bad patterns
into this codebase, so it should be ignored by default.

If investigation into the BBL data format gets genuinely stuck, Claude may ask
the developer about the prototype and examine it as a last resort. General notes
on how it operates may be recorded here, but its location and code must **not**
be.
